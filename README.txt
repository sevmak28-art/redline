REDLINE — автомобильный каталог и поисковый портал
==================================================

ЧТО ЕСТЬ В ПРОЕКТЕ
- Адаптивный автомобильный каталог, страницы производителей, поиск, избранное и сравнение.
- Страница LIVE объявлений с проверкой состояния API и автоматическим обновлением страницы.
- Сервер на Python standard library: JSON feed connector, SQLite, API, планировщик.
- Фильтр: статус должен быть active, источник должен подтвердить запись в течение 15 минут, срок действия не должен истечь.
- Фото и номера телефонов публикуются только при наличии отдельного права на повторный показ.
- Автоматический сбор HTML / обход закрытых страниц НЕ используется.

ПРОСМОТР СТАТИЧЕСКОГО САЙТА
1. Распакуй ZIP.
2. Открой папку redline_site.
3. Для каталога можно открыть index.html напрямую, но API-лента требует сервер.

ЗАПУСК СЕРВЕРА (Windows 11)
1. Открой папку redline_site.
2. Дважды нажми START_REDLINE.bat.
3. Открой http://127.0.0.1:8000/listings.html.
4. Не закрывай чёрное окно, пока пользуешься сайтом. Для остановки нажми Ctrl+C.

Для защищённого ручного запуска API-синхронизации задай REDLINE_ADMIN_TOKEN в переменных окружения перед запуском server.py.

Для остановки сервера нажми Ctrl+C.

ПОДКЛЮЧЕНИЕ РЕАЛЬНЫХ ОБЪЯВЛЕНИЙ
Все источники в providers.json пока выключены. Для настоящей ленты площадка должна предоставить официальный API или партнёрский JSON-фид и разрешить объём повторного показа данных.
1. Запроси API/фид у площадки.
2. Настрой providers.json по образцу providers.example.json.
3. Добавь API-токен в переменные окружения, не в HTML/JS.
4. Включай фото/телефон только после явного письменного разрешения.
5. Перезапусти server.py.
Подробности — docs/API-CONNECTOR.md и заготовка письма — docs/PARTNER-REQUEST.md.

API
GET  /api/health
GET  /api/sources
GET  /api/listings?q=Toyota&region=Ош
POST /api/admin/sync   (заголовок X-REDLINE-ADMIN)

ПУБЛИКАЦИЯ В ИНТЕРНЕТ
Проект подготовлен для Render Blueprint: файл render.yaml создаёт Python Web Service, проверку /api/health, постоянный диск /var/data и секрет REDLINE_ADMIN_TOKEN. Для SQLite нужен платный Web Service с Persistent Disk — без него хранилище Render эфемерное.
1. Загрузи содержимое папки redline_site в GitHub-репозиторий.
2. В Render выбери New -> Blueprint и подключи этот репозиторий.
3. После деплоя проверь адрес *.onrender.com и /api/health.
4. Для собственного домена добавь его в Settings -> Custom Domains, настрой DNS по значениям Render и нажми Verify. Render автоматически выдаёт/продлевает TLS-сертификат и перенаправляет HTTP на HTTPS.
5. В Render Environment укажи REDLINE_PUBLIC_URL=https://твой-домен и сделай redeploy.
Подробная русская инструкция: DEPLOY-RENDER-RU.md. CI: .github/workflows/ci.yml. Не публикуй secret, .env или SQLite с персональными данными.

ВАЖНО
На данный момент официальные API/партнёрские фиды площадок ещё не выданы, поэтому настоящие объявления не появляются автоматически. REDLINE честно показывает статус «источники не подключены», а не выдумывает карточки. Проверенные внешние поисковые ссылки остаются доступны в разделе объявлений.
