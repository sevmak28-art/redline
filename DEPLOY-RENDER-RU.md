# Публикация REDLINE в интернете (Render)

В проект уже добавлен `render.yaml`. Он описывает Python Web Service в регионе Singapore, проверку `/api/health`, переменные окружения и постоянный диск `/var/data` для SQLite.

## Перед началом

- Нужен аккаунт GitHub (репозиторий можно сделать Private).
- Нужен аккаунт Render.
- Для сохранения SQLite после перезапуска нужен платный Web Service и Persistent Disk: Render указывает, что постоянные диски доступны платным сервисам; без диска файловая система эфемерная.
- Собственный домен приобретается отдельно у регистратора. До покупки можно проверить приложение на бесплатном адресе `*.onrender.com`, если выбранный план/доступ позволяет.

## 1. Загрузить проект в GitHub

1. Распакуй `REDLINE_3.1_live_connector.zip`.
2. Создай новый репозиторий на GitHub, например `redline-auto-portal`.
3. Загрузи в корень репозитория всё содержимое папки `redline_site` (не саму папку как вложенную).
4. Проверь, что в корне GitHub видны `render.yaml`, `server.py`, `index.html`, `requirements.txt`, папки `assets`, `tests` и `.github/workflows`.
5. Не загружай `.env`, `server_data`, секретные API-ключи или пользовательские данные. `.gitignore` уже исключает эти файлы.
6. GitHub Actions автоматически запустит проверки проекта при отправке файлов.

## 2. Создать сервис на Render

1. Открой https://dashboard.render.com/ и войди в аккаунт.
2. Нажми **New → Blueprint**.
3. Подключи GitHub и выбери репозиторий `redline-auto-portal`.
4. Render прочитает `render.yaml`. Проверь регион Singapore и параметры сервиса. Автодеплой настроен на успешное прохождение GitHub Checks.
5. Подтверди создание ресурсов и выбери подходящий платный план. Persistent Disk нужен, чтобы SQLite-база не исчезала при деплое или перезапуске.
6. После успешного деплоя открой адрес `https://<имя-сервиса>.onrender.com`.

Render должен направлять публичный порт через переменную `PORT`; приложение уже слушает `0.0.0.0` и использует `PORT`. HTTPS завершается на прокси Render.

## 3. Подключить собственный домен

1. Купи домен у регистратора. Имя REDLINE может быть занято — проверь доступность до оплаты.
2. В Render открой сервис → **Settings → Custom Domains → Add Custom Domain**.
3. Введи купленный домен (например, `www.example.com`).
4. В панели DNS-регистратора добавь записи ровно с теми значениями, которые покажет Render. Для поддомена обычно используется CNAME на хост Render; для корневого домена следуй подсказкам Render/регистратора.
5. Удали конфликтующие AAAA-записи, если Render просит это сделать.
6. Вернись в Render и нажми **Verify**. После подтверждения Render автоматически выпустит и будет продлевать TLS-сертификат, а HTTP будет перенаправляться на HTTPS.
7. В Render → Environment добавь `REDLINE_PUBLIC_URL=https://твой-домен.example` (без завершающего слэша) и перезапусти/задеплой сервис.

## 4. Проверка после публикации

Открой эти адреса, заменив домен:

- `https://твой-домен.example/` — главная.
- `https://твой-домен.example/api/health` — состояние сервера и источников объявлений.
- `https://твой-домен.example/sitemap.xml` — карта сайта с абсолютными HTTPS-ссылками.
- `https://твой-домен.example/robots.txt` — правила для поисковых роботов.
- `https://твой-домен.example/listings.html` — раздел объявлений.

Проверь, что `http://твой-домен.example` перенаправляется на HTTPS и браузер показывает замок.

## 5. Секреты и безопасность

- `REDLINE_ADMIN_TOKEN` генерируется Render автоматически через `generateValue`.
- Не вставляй секреты в HTML, JavaScript, GitHub или `providers.json`.
- Секреты партнёрских API добавляй в Render → Environment, а в `providers.json` указывай имя переменной `token_env`.
- Не включай источник в `providers.json`, пока у тебя нет официального API/JSON-фида и письменного разрешения на повторное отображение полей.
- Не отключай фильтрацию устаревших объявлений.

## Что не сделано автоматически

Этот пакет не покупает домен, не создаёт аккаунты GitHub/Render и не выполняет публикацию вместо владельца. Эти шаги требуют входа в твои личные аккаунты и оплату домена/хостинга. Сам проект подготовлен к Render Blueprint; DNS и домен включаются после того, как ты их выберешь.
